# Gene Peer Evolution

Every Gene node is an independently developing Gene instance, not a subordinate worker.

## Core rules

1. Each Gene keeps its own cryptographic identity, state, memory, development journal, experiments and signed evolution ledger.
2. Any Gene may communicate with any other Gene through authenticated peer messages.
3. Any Gene may publish signed knowledge/evidence for others to inspect.
4. Shared knowledge is advisory evidence, not authority. A recipient may adopt, challenge, reject or defer it.
5. Independent disagreement is preserved because diversity is useful for finding failures and alternative solutions.
6. Validated improvements can be shared rapidly, but structural source promotion still requires tests and independent validator quorum.
7. Replication and communication occur only inside authorized infrastructure; there is no uncontrolled propagation to third-party systems.

## Desired effect

The Gene family behaves like a population of related but independently learning systems. They can specialize, compete, ask for help, exchange discoveries and selectively inherit useful validated learning without collapsing into one synchronized state.
