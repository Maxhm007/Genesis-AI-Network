Issue Solver

Every actionable development task is tracked through GitHub Issues. Genesis routes the issue into the safest compatible lane, repairs only within its bounded scope, validates the candidate, and closes only after verified promotion or a terminal bounded outcome.

3Bounded repairOne reserved repair at a time. The worker reads current code, issue evidence, and previous failed strategies before proposing a candidate.
